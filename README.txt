This page is adapted from https://qse-phdschool.spilab.es/.
The original homepage was downloaded on 14 October 2026. Its original
header and hero markup, logo, favicon and complete
stylesheet form the basis of this page. The original styles.css is unchanged;
announcement.css contains the edition-specific refinements.

GOOGLE FORM
Both “Keep me informed” links open https://bit.ly/4yosF5c.
To change the form later, edit googleFormUrl in dist/config.js and update
the matching href values in dist/index.html (the no-JavaScript fallback).

HOW TO HOST
Upload the contents of dist/ to any static website host. There is no build
step, dependency installation or server application required.

The first-edition links currently use https://qse-phdschool.spilab.es/.
If this page replaces that address, first move the old site to a permanent
archive address, then update the two first-edition links in index.html.
Otherwise they will point back to the new landing page.

The first edition's programme, lecturers, venue information and organiser
footer were removed rather than being presented as confirmed for 2027.
Original first-edition analytics and carousel scripts are not loaded.
The font is Inter, loaded from Google Fonts, with system-font fallbacks.

Files in dist/ are the deployable website. The .openai folder holds separate
private-preview hosting configuration and is not needed for your own host.

CONTENT UPDATE
The original motto and About the School copy are retained. The venue
paragraph is updated for CEUB in Bertinoro, based on https://www.ceub.it/location/.
The first-edition statistics (3 days, 12 lecturers, 2 social activities)
are labelled as 2026 figures; counts come from the original homepage.
